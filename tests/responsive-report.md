# 响应式尺寸切换回归报告

验证日期：2026-10-02。环境：Codex 内置浏览器，在可调整尺寸的同源 iframe 中运行真实 Vue、Vue Router、GSAP 和 WebGL 场景。

## 复现与修复

1. 从首页进入 Projects，缩到手机尺寸，再恢复桌面：导航容器变回 `display:flex`，但四个按钮仍是空文字、`display:none`。现在会同时恢复按钮内容、显示状态、首页文字与 ASCII 可见度。
2. 在入场或切页动画中改变尺寸：旧动画及异步流程可能继续改写新界面。现在动画由当前场景统一管理，取消会结束对应 Promise；过期的加载、切页续体及 `finally` 不再修改新场景。
3. 在切页中通过历史导航连续改变路由：现在以最新路由为准，包括目标再次变回当前页面的情况。
4. 窗口宽 1920px、高 390px 或 160px：About 文字与 Contact 换行徽章可能超出屏幕，原先不能滚动访问。现在静态子页同时考虑高度来调整字号，并允许实际内容溢出时滚动；Projects 的滚动区域也随窗口高度调整。

保持原有响应式策略：进入手机模式回到首页，恢复桌面后显示首页及完整导航；桌面范围内缩放保留当前页面。离开页面时清除其滚动和动画状态。ASCII 与 3D 人物仍在同一动画循环中逐帧更新。

## 复测

运行 `npm test`。启动 `npm run dev`，打开 `/tests/responsive.html`，点击 **Run tests**，运行全部场景；`?suite=extra` 运行补充场景及桌面布局回归，`?case=short` 单独验证超短窗口。
